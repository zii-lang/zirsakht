The struct `ResolvedSourcePath` has the path model as defined below:

## Project Files
```
absolutePath = /home/user/project/src/main.z
logicalPath  = src/main.z
origin       = Project
```

### Library Files
```
absolutePath = /x/y/z/lib_1/runtime/core.lambda
logicalPath  = lib_1/runtime/core.lambda
origin       = Library
libraryName  = lib_1
```
